# Input Guide (`examples/sample_input.json`)

This guide explains each field in `examples/sample_input.json`.

These values are simple, approximate inputs for everyday footwear fit exploration only.

## Field-by-field explanation

### `left_foot_length_mm`
Approximate left foot length in millimeters.
Measure from heel to longest toe.

### `right_foot_length_mm`
Approximate right foot length in millimeters.
Measure from heel to longest toe.

### `left_forefoot_width_mm`
Approximate left forefoot width in millimeters.
Measure across the widest front part of the foot.

### `right_forefoot_width_mm`
Approximate right forefoot width in millimeters.
Measure across the widest front part of the foot.

### `arch_height_level`
Simple arch-height category.
Use one of the project-supported levels (for example: `low`, `medium`, `high`).

### `instep_pressure_level`
Simple top-of-foot pressure category in regular shoes.
Use one of the project-supported levels (for example: `none`, `mild`, `moderate`).

### `use_case`
General day-to-day usage context.
Example from the sample input: `daily_walking`.

### `in_shoe_space_preference`
How much in-shoe space you prefer.
Use one of the project-supported levels (for example: `low`, `medium`, `high`).

## Important notes

- Measurements are approximate.
- Small measuring differences are normal.
- Use this tool for everyday footwear fit exploration and 3D printing experimentation only.
