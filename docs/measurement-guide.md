# Measurement Guide (Simple)

Measure in millimeters using a ruler/tape:

1. Foot length: heel to longest toe (left and right).
2. Forefoot width: widest metatarsal area (left and right).
3. Select arch height level: low / medium / high.
4. Select instep pressure level in normal shoes: none / mild / moderate / high.
5. Select use case: daily_walking / standing / indoor / light_activity.
6. Select in-shoe space preference: thin / medium / thick.

Tip: Measure both feet and avoid rounding too aggressively.
