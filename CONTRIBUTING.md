# Contributing

Thank you for contributing to this independent open-source edition.

## Scope of contributions

Please focus contributions on:
- Safety boundary clarity
- Documentation improvements
- Usability improvements
- Tests and CI quality
- Basic geometry improvements

## Required boundaries

- Do **not** submit proprietary Anburan Core logic.
- Do **not** submit medical or clinical claims.
- Do **not** submit real user private data.
- All contributions must respect the project's non-medical boundary.
